API 1 of 4

Language Detector

  • Identify the language of any text string
  • Returns ranked array of {detectedLanguage, confidence}
  • BCP-47 codes — e.g. "fr", "zh-Hant"
  • Used here: Auto-detect source language in Translate view
const detector = await LanguageDetector.create(); const results = await detector.detect("Bonjour!"); // [{detectedLanguage:"fr",confidence:0.98},…]
API 2 of 4

Translator

  • 30+ language pairs supported
  • Synchronous or streaming translation
  • Session-based — create once, reuse for many translations
  • Monitor callback for model download progress
  • Used here: Google-Translate-style UI with language swap
const t = await Translator.create({ sourceLanguage: "fr", targetLanguage: "en" }); const out = await t.translate("Bonjour!"); // "Hello!"
API 3 of 4

Summarizer

  • type: key-points · tldr · teaser · headline
  • format: plain-text or markdown
  • length: short · medium · long
  • Optional context hint orients the model
  • Streaming via summarizeStreaming() — live output
const s = await Summarizer.create({ type: "key-points", format: "plain-text", length: "medium" }); for await (const chunk of s.summarizeStreaming(text)) { display(chunk); // streaming delta }
API 4 of 4

Prompt API (LanguageModel)

  • Full conversational access to Gemini Nano
  • System prompt via initialPrompts
  • Multimodal: text + image input
  • Streaming via promptStreaming()
  • Temperature / top-K sampling controls
const session = await LanguageModel.create({ expectedInputs: [ {type: "text"}, {type: "image"} ], temperature: 0.8 }); for await (const chunk of session.promptStreaming(input)) { display(chunk); }
Standardization

W3C Web ML Community Group + browser roadmap

  • All four APIs are proposals in the W3C Web Machine Learning Community Group
  • Reviewed by W3C TAG (Technical Architecture Group)
  • Specs at webmachinelearning.github.io
  • Translation/Detection: WICG/translation-api
  • Summarizer/Writer: writing-assistance-apis
  • Prompt: explainers-by-googlers/prompt-api
  • Early-stage proposals — not yet ratified standards
